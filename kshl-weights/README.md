# kshl-weights

한국수어 인식 모델 가중치. [한국수어 양방향 번역 앱](../../)에서 수어 영상을 한국어 단어로 옮기는 데 쓰입니다.

## 담긴 것

| 경로 | 크기 | 내용 |
|---|---|---|
| `ksl_mp_model/best.safetensors` | 16MB | 트랜스포머 가중치 (어댑터가 아니라 전체 가중치) |
| `ksl_mp_model/config.json` | 332B | 구조·학습 설정과 검증 점수 |

모델은 `WORD0001` 부터 `WORD3000` 까지의 클래스 id를 예측합니다. id를 한국어 단어로 되돌리는 정렬표(`label_map_ko.json`)는 **여기 담지 않았습니다.** AI-Hub 라벨 아카이브에서 파생된 자료라 재배포할 수 없습니다. AI-Hub 계정으로 `[라벨]01_real_word_morpheme.zip` 을 내려받은 뒤 앱 저장소의 스크립트로 직접 만드십시오.

```bash
python build_label_map_ko.py ~/Downloads/[라벨]01_real_word_morpheme.zip
```

## 모델

- 구조: 트랜스포머 인코더, dim 256 · depth 4 · heads 4
- 클래스: 3,000 (한국어 단어)
- 입력: 표준 키포인트 55점 × 3채널 × 64프레임
  - 상반신 13점 + 왼손 21점 + 오른손 21점
  - 목을 원점, 어깨 너비를 1로 정규화
  - 클립 길이와 무관하게 64프레임으로 리샘플

키포인트는 MediaPipe Holistic(`model_complexity=1`)으로 뽑습니다. **이 값을 2로 올리면 손 검출률은 0.61에서 0.80으로 오르지만 실측 top-1은 0.283에서 0.192로 떨어집니다.** 학습 캐시가 1로 추출됐기 때문이며, 추론도 1로 맞춰야 합니다.

## 성능

| 평가 | top-1 | top-5 |
|---|---|---|
| AI-Hub 자체 검증셋 | 0.958 | 0.997 |
| 자체 녹화 100클립 (화자 독립, 후보 3,000) | **0.610** | **0.760** |

아래 숫자가 앱을 설명하는 값입니다. 위 숫자는 같은 스튜디오·같은 카메라·같은 화자들이라 실사용 성능이 아닙니다. 참고로 이전 모델(OpenPose 키포인트 기반)은 같은 100클립에서 top-1 0.283이었습니다.

후보를 실제 녹화한 100단어로 제한하면 top-1 은 0.770 으로 오릅니다.

## 쓰는 법

```bash
export KSL_KP_MODEL=/path/to/kshl-weights/ksl_mp_model
export KSL_LABEL_MAP_KO=/path/to/ksl_model/label_map_ko.json   # 직접 생성한 정렬표
./server/run_kp.sh
```

디렉터리(파일이 아니라)를 가리키면 서버가 표준 키포인트 모델로 인식합니다.

## 학습 데이터 출처

AI-Hub 한국수어 영상 데이터셋에서 뽑은 3,000단어 키포인트 시퀀스로 학습했습니다. 원본 영상은 포함하지 않으며, 학습에도 좌표만 사용했습니다.

AI-Hub 이용 약관은 학습된 가중치의 공개는 허용하지만 말뭉치와 그 정렬표의 재배포는 허용하지 않습니다. 그래서 이 저장소에는 가중치만 담고, 라벨 정렬표는 제외했습니다.
